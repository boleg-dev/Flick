# Flick

Flick switches between visible windows on the Mac.

## Language

**Switching session**: One visit to the window switcher, from opening it until choosing a window or cancelling. It can begin with a keyboard shortcut or from the menu.

**Selection**: The window that will receive focus when the switching session is confirmed.

**Window preview**: A captured image of a window shown in the switcher. When capture is unavailable, the application icon stands in for the preview.

**Scope**: The set of windows offered in a switching session: all visible windows or those belonging to the current application.
